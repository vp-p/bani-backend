# Neo Curator

Neo Curator is a personal knowledge management platform designed to replace passive content consumption with intentional learning.

The project centralizes knowledge from multiple sources into a single library, allowing users to organize, curate, and discover content through topics, collections, and transparent recommendations. Instead of maximizing engagement with infinite scrolling, Neo Curator aims to help users build meaningful learning habits.

## Features (MVP)
- Personal knowledge library
- Content management
- Topic organization
- Tags
- Collections
- Multiple content sources
- Search
- Activity history
- Weight-based content prioritization

## Planned Features

- Daily learning sessions
- Explainable recommendation engine
- Integration with different platforms and knowledge sources, like YouTube, Substack, Wikipedia, etc.
- Semantic search with embeddings
- AI-assisted summaries and tagging
- Knowledge graph
- Rabbit hole (Personalized learning paths)
- Learning analytics dashboard

## Project Goals
Neo Curator aims to become a Personal Knowledge Operating System (PKOS), providing a centralized environment where users can collect, organize, and manage knowledge from multiple sources in a single place. Rather than encouraging endless content consumption, the project is designed to promote intentional learning by helping users focus on subjects that genuinely matter to them.

The long-term vision is to replace algorithm-driven, engagement-focused feeds with a transparent recommendation system that prioritizes curiosity, learning, and personal growth. Every recommendation should be explainable, allowing users to understand why a piece of content was suggested and to maintain full control over the algorithm's behavior.

By combining a personal knowledge library, content organization, activity tracking, and intelligent recommendations, Neo Curator seeks to become a platform that empowers users to continuously explore, connect, and deepen their understanding of the topics they care about, without the distractions of infinite scrolling or engagement-driven social media.
